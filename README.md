# Paradise Nursery Shopping Application

A responsive React shopping-cart application for an online plant shop.

## Features
- Landing page with a background image and Get Started button
- About Us section
- Three plant categories with six plants per category
- Product images, descriptions, and prices
- Redux Toolkit cart state
- Add-to-cart buttons that disable after adding
- Dynamic cart item count
- Quantity increment/decrement and item removal
- Per-item and overall totals
- Checkout Coming Soon message
- Continue Shopping navigation

## Tech Stack
React, Vite, Redux Toolkit, React Redux, Lucide React, CSS

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

This project is an educational implementation. Product images are loaded from Unsplash.
